# Pinterest Clone

Un clone de la célèbre plateforme de partage d'images Pinterest, développé dans le cadre d'un projet personnel. Cette application permet de naviguer à travers des photos, de les aimer et de laisser des commentaires.

## Fonctionnalités
* **Galerie d'images :** Affichage d'un flux de photos inspiré de Pinterest.
* **Interactivité :** Possibilité de liker (aimer) les photos.
* **Espace de discussion :** Ajout de commentaires sur les publications.

---

## Prérequis
Avant de lancer l'application, assurez-vous d'avoir installé :
* [Node.js](https://nodejs.org/)
